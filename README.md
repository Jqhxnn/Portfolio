## Portfolio

This is my personal portfolio that I also use for learning new stuff like implementing API's such as the [Last.fm API](https://www.last.fm/api). 
I learned many new tricks that improve the users experience on the website as well as the performance.

### Preview

You can visit the website at any time [here](https://jqhxnn.vercel.app). I constantly try to improve my portfolio, so it is worth visiting it.

### Tech Stack

I built this portfolio with [Next.js](https://nextjs.org), using JSX for the frontend and JavaScript for the backend API routes.
